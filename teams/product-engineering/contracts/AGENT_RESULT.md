# Agent Result Contract

## Task
Task ID and objective.

## Outcome
COMPLETE / PARTIAL / BLOCKED

## Changes or findings
Concrete files/symbols/behavior/evidence.

## Acceptance coverage
AC IDs addressed and how.

## Validation
Exact commands/flows and outcomes. Unexecuted checks are never PASS.

## Contract changes
API/schema/state/interface deviations, or none.

## Assumptions
Confirmed vs inferred.

## Residual risks / blockers
What the main lead must integrate, verify, or escalate.
